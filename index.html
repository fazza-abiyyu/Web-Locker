Install in 30 Seconds

Load it manually into Chrome, Edge or Firefox.

1

Clone Repository

Download the extension files to your computer.

git clone https://github.com/fazza-abiyyu/Web-Locker.git
2

Open Extensions Page

Paste this into your browser's address bar.

chrome://extensions/
3

Enable & Load

Turn on Developer Mode (usually top right). Then click Load unpacked and select the downloaded Web-Locker folder. You're done!
